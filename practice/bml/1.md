## Q5 — OLS Assumptions

**Your answer: (a), (e)**
**Correct: (a), (b), (c), (e)**

You missed **(b)** and **(c)**.

**(b) Errors have expected value zero — TRUE** ✓

$$E[\epsilon_i] = 0 \quad \text{for all } i$$

This ensures the estimator is **unbiased** — on average the model neither over nor under predicts. This is a fundamental OLS assumption.

**(c) Independent variable $x$ is error-free — TRUE** ✓

OLS assumes ALL randomness is in the error term $\epsilon$. The $x$ values are treated as fixed, known constants with no measurement error. If $x$ also had error, we would need a different model (errors-in-variables).

$$\boxed{\text{Correct: (a), (b), (c), (e)}}$$

## Q6 — $R^2$ and Adjusted $R^2$

**Your answer:** $R^2 = 0.25$, Adjusted $= -8$
**Correct:** $R^2 = 0.75$, Adjusted $= 0.71$

You computed $R^2 = SSE/SST$ instead of $1 - SSE/SST$.

**$R^2$:**

$$R^2 = 1 - \frac{SSE}{SST} = 1 - \frac{50}{200} = 1 - 0.25 = \boxed{0.75}$$

**Adjusted $R^2$:**

$$R^2_{adj} = 1 - (1-R^2)\frac{n-1}{n-p-1} = 1 - (0.25)\frac{24}{21}$$

$$= 1 - 0.25 \times 1.143 = 1 - 0.286 = \boxed{0.714}$$

> **Key formula:** $R^2 = 1 - \frac{SSE}{SST}$ — never forget the $1-$.

## Q8 — Properties of $R^2$

**Your answer: (a), (b), (d), (e)**
**Correct: (a), (b), (d)**

You incorrectly selected **(e)**.

**(e) "High $R^2$ guarantees a good model" — FALSE** ✗

This is the **Anscombe's Quartet** lesson. Four completely different datasets can have identical $R^2$ values. High $R^2$ does NOT mean:
- The linear model is appropriate (non-linearity may exist)
- The model will generalise well
- There are no outliers driving the fit

Always check residual plots alongside $R^2$.

## Q10 — K-Means Properties

**Your answer: (a), (c)**
**Correct: (a), (c), (d)**

You missed **(d)**.

**(d) "Objective function never increases between iterations" — TRUE** ✓

This is a guarantee of the K-means algorithm. In BOTH steps:

**Assignment step:** Each point moves to its nearest centroid → within-cluster SS can only decrease or stay the same.

**Update step:** Recomputing centroid as mean minimises SS for that cluster → SS can only decrease or stay the same.

$$J_{k+1} \leq J_k \quad \text{always}$$

This guarantees **convergence** — though NOT to the global optimum.

$$\boxed{\text{Correct: (a), (c), (d)}}$$

## Q18 — Logistic Regression Properties

**Your answer: (a), (c), (d), (e)**
**Correct: (a), (c), (e)**

You incorrectly selected **(d)**.

**(d) "Decision boundary is always linear in feature space" — FALSE** ✗

The decision boundary is linear in the **original feature space** ONLY when features are used as-is. But:

- If you add polynomial features ($x^2$, $x_1x_2$) → boundary is **non-linear** in original space
- The boundary is linear in the **transformed/expanded feature space** — not necessarily in the original

The question says "always linear in feature space" — the word "always" makes it false. It is only linear when no feature transformation is applied.

> Compare with statement (c): "log-odds is linear in features" — this IS always true by the model definition. The decision boundary being linear is a consequence, but adding polynomial features breaks it.

$$\boxed{\text{Correct: (a), (c), (e)}}$$

## Q20 — Bias-Variance Tradeoff

**Your answer: (a), (b), (c), (e)**
**Correct: (a), (b), (d), (e)**

You selected **(c)** instead of **(d)**.

**(c) "Adding more training data primarily reduces bias" — FALSE** ✗

More training data primarily reduces **VARIANCE**, not bias.

```
Bias = determined by model complexity/form
       → fixed by the model choice
       → more data does NOT help bias

Variance = how much model changes with different training sets
         → more data → more stable model → VARIANCE decreases
```

A simple model (high bias) with more data is still a simple model — it still misses the true pattern. Bias only decreases by choosing a more complex model.

**(d) "Regularisation reduces variance at the cost of some bias" — TRUE** ✓

Regularisation (like Ridge) shrinks coefficients:
- Introduces some bias (predictions slightly off)
- But greatly reduces variance (model more stable)
- Net effect: lower test error ✓

This is the classic **bias-variance tradeoff** in action.

$$\boxed{\text{Correct: (a), (b), (d), (e)}}$$
