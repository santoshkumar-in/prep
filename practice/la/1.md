## Q5 — Determinant of Matrix with Complex Eigenvalues

**Your answer: (c) $2+2i$**
**Correct: (b) 4**

Given: $3\times3$ real matrix with eigenvalues $(1+i)$ and $2$.

**Key rule:** Real matrices always have complex eigenvalues in **conjugate pairs**.

So if $(1+i)$ is an eigenvalue → $(1-i)$ must also be an eigenvalue.

Three eigenvalues: $\lambda_1 = 1+i$, $\lambda_2 = 1-i$, $\lambda_3 = 2$

$$\det(A) = \lambda_1 \cdot \lambda_2 \cdot \lambda_3 = (1+i)(1-i)(2)$$

$$(1+i)(1-i) = 1^2 + 1^2 = 2$$

$$\det(A) = 2 \times 2 = \boxed{4}$$

> **Key formula:** $(1+i)(1-i) = 1 - i^2 = 1-(-1) = 2$. Product of conjugate pair is always REAL.

## Q10 — Projection Matrix Properties

**Your answer: (a), (b), (d)**
**Correct: (a), (b), (d), (e)**

You missed **(e)**.

**(e) $\text{rank}(P) = \text{tr}(P)$ — TRUE** ✓

Since eigenvalues of $P$ are only 0 or 1 (which you correctly identified in (d)):

$$\text{tr}(P) = \sum_i \lambda_i = \text{count of eigenvalues equal to 1} = \text{rank}(P)$$

**Why:** Rank = number of non-zero eigenvalues = number of 1-eigenvalues. Trace = sum of eigenvalues = sum of 1s = count of 1-eigenvalues. They are the same thing.

**Concrete example:** If $P$ is $4\times4$ with rank 2:
- Eigenvalues: $1, 1, 0, 0$
- $\text{tr}(P) = 1+1+0+0 = 2 = \text{rank}(P)$ ✓

$$\boxed{\text{Correct: (a), (b), (d), (e)}}$$

## Q17 — SVD Properties

**Your answer: (a), (b), (e)**
**Correct: (a), (b), (c), (e)**

You missed **(c)**.

**(c) $\text{rank}(A)$ equals the number of non-zero singular values — TRUE** ✓

This is a fundamental result of SVD:

$$A = U\Sigma V^T = \sum_{i=1}^r \sigma_i \mathbf{u}_i\mathbf{v}_i^T$$

where $r$ = number of non-zero $\sigma_i$.

Each non-zero singular value contributes one rank-1 term. So:

$$\text{rank}(A) = \text{number of non-zero singular values}$$

**Example:** If $\Sigma = \begin{bmatrix}5&0&0\\0&3&0\\0&0&0\end{bmatrix}$, rank $= 2$ (two non-zero singular values).

This is actually one of the most useful properties of SVD — it reveals the rank directly from the diagonal of $\Sigma$.

$$\boxed{\text{Correct: (a), (b), (c), (e)}}$$
