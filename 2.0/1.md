#### TOPIC 1 — PDF Normalisation and Moments

**Three-step recipe — never skip any step:**

$$\textbf{Step 1: Find k} \implies \int f(x)\,dx = 1$$

$$\textbf{Step 2: Find } E[X] \implies \int x\cdot f(x)\,dx$$

$$\textbf{Step 3: Find } E[X^2] \implies \int x^2\cdot f(x)\,dx$$

$$\textbf{Step 4: Var}(X) = E[X^2] - (E[X])^2$$

**Common integrals to memorise:**

$$\int_0^1 x^n\,dx = \frac{1}{n+1}$$

$$\int_0^1 x(1-x)\,dx = \int_0^1(x-x^2)\,dx = \frac{1}{2}-\frac{1}{3} = \frac{1}{6}$$

$$\int_0^1 x^2(1-x)\,dx = \frac{1}{3}-\frac{1}{4} = \frac{1}{12}$$

**Practice set — do these until automatic:**

| PDF | $k$ | $E[X]$ | $\text{Var}(X)$ |
|-----|-----|--------|-----------------|
| $kx$ on $[0,2]$ | 1/2 | 4/3 | 2/9 |
| $k(1-x)$ on $[0,1]$ | 2 | 1/3 | 1/18 |
| $kx^2$ on $[0,3]$ | 1/9 | 9/4 | 27/80 |
| $kx(1-x)$ on $[0,1]$ | **6** | **1/2** | **1/20** |
| $ke^{-x}$ on $[0,\infty)$ | 1 | 1 | 1 |

#### TOPIC 2 — $R^2$ Formula

**One formula, four ways to write it:**

$$R^2 = 1 - \frac{SSE}{SST} = \frac{SSReg}{SST} = \frac{SST-SSE}{SST} = r^2 \text{ (simple LR only)}$$

**Memory trick:** $R^2$ is how much you EXPLAINED. $SSE/SST$ is how much you FAILED. So $R^2 = 1 - \text{failure}$.

**Practice — fill this table:**

| $SST$ | $SSE$ | $SSReg$ | $R^2$ |
|-------|-------|---------|-------|
| 100 | 40 | 60 | 0.60 |
| 500 | 100 | 400 | **0.80** |
| 200 | 50 | 150 | **0.75** |
| 300 | 300 | 0 | **0** |
| 400 | 0 | 400 | **1.0** |

#### TOPIC 3 — Bayes Theorem Denominator Rule

**The rule you must tattoo in your brain:**

$$\text{The condition AFTER } | \text{ → find that row/column → sum it → denominator}$$

**Quick drill:**

| Question | Given (after |) | Denominator |
|----------|----------------|-------------|
| $P(D\|T^+)$ | Test positive → row | Total test positive |
| $P(D\|T^-)$ | Test negative → row | Total test negative |
| $P(T^+\|D)$ | Has disease → column | Total with disease |
| $P(T^+\|D^c)$ | No disease → column | Total without disease |

**Always build the table with 10,000 people. Never skip this step.**

#### TOPIC 4 — WITH vs WITHOUT Replacement

| | With Replacement | Without Replacement |
|-|-----------------|---------------------|
| Denominator | Same each draw | Decreases by 1 |
| Events | Independent | Dependent |
| Formula | $\left(\frac{r}{n}\right)^k$ | $\frac{{}^rC_k}{{}^nC_k}$ |
| Example (5 red, 3 blue, 2 draws, both red) | $\frac{5}{8}\times\frac{5}{8}=\frac{25}{64}$ | $\frac{5}{8}\times\frac{4}{7}=\frac{20}{56}=\frac{5}{14}$ |

**Trigger word:** "WITH replacement" → use $n^k$ in denominator. "WITHOUT replacement" → use $n\times(n-1)\times\cdots$

#### TOPIC 5 — Central Limit Theorem

**Three facts — all three always true:**

$$\bar{X} \sim N\left(\mu,\ \frac{\sigma^2}{n}\right) \quad \text{for large } n$$

| Property | Statement |
|----------|-----------|
| Works for ANY population distribution | No normality assumption on population |
| $n\geq30$ | Rule of thumb only — not strict |
| More data | $\bar{X}$ concentrates more around $\mu$ |

**What CLT does NOT say:**
- Does NOT require normal population
- Does NOT work for $n=2$
- Does NOT reduce bias

#### TOPIC 1 — Eigenvalue Computation

**The ONE rule that catches all mistakes:**

> Diagonal entries = eigenvalues ONLY for diagonal or triangular matrices.
> For all other matrices: ALWAYS solve $\det(A-\lambda I)=0$.

**Algorithm — never skip steps:**

```
Step 1: Write (A - λI)
Step 2: Compute det(A - λI) = 0
Step 3: Solve the polynomial for λ
Step 4: VERIFY: Σλᵢ = tr(A) and Πλᵢ = det(A)
Step 5: For each λ, solve (A-λI)v = 0
```

**2×2 characteristic equation shortcut:**

$$\det\begin{bmatrix}a-\lambda & b \\ c & d-\lambda\end{bmatrix} = \lambda^2 - (a+d)\lambda + (ad-bc) = 0$$

$$\lambda^2 - \text{tr}(A)\cdot\lambda + \det(A) = 0$$

**Practice set:**

| Matrix | tr | det | Eigenvalues |
|--------|----|-----|-------------|
| $\begin{bmatrix}3&1\\1&3\end{bmatrix}$ | 6 | 8 | 2, 4 |
| $\begin{bmatrix}0&1\\-2&3\end{bmatrix}$ | 3 | 2 | **1, 2** |
| $\begin{bmatrix}4&1\\2&3\end{bmatrix}$ | 7 | 10 | **2, 5** |
| $\begin{bmatrix}1&0\\0&1\end{bmatrix}$ | 2 | 1 | **1, 1** |
| $\begin{bmatrix}2&1\\0&3\end{bmatrix}$ | 5 | 6 | **2, 3** (triangular!) |

#### TOPIC 2 — Matrix Types and Eigenvalue Guarantees

**The most tested comparison in exams:**

| Matrix Type | Definition | Eigenvalue Guarantee |
|-------------|-----------|---------------------|
| **Symmetric** | $A=A^T$ | All eigenvalues **REAL** |
| **Orthogonal** | $Q^TQ=I$ | $|\lambda|=1$ (can be complex!) |
| **Positive Definite** | $\mathbf{x}^TA\mathbf{x}>0$ | All eigenvalues **REAL and POSITIVE** |
| **Idempotent** | $P^2=P$ | Eigenvalues only **0 or 1** |
| **Diagonal/Triangular** | — | Eigenvalues = diagonal entries |

**Memory device:**
```
Symmetric → Real (S and R go together)
Orthogonal → |λ|=1 (rotation/reflection, can be complex)
Positive Definite → Real + Positive (strongest condition)
```

#### TOPIC 3 — Four Fundamental Subspaces

**The complete map:**

```
For A (m×n, rank r):

In ℝⁿ (domain):                In ℝᵐ (codomain):
┌─────────────────┐             ┌─────────────────┐
│   Row space     │             │  Column space   │
│   dim = r       │─── A ──────▶│   dim = r       │
├─────────────────┤      ⊥      ├─────────────────┤
│   Null space    │             │  Left null space│
│   dim = n-r     │             │   dim = m-r     │
└─────────────────┘             └─────────────────┘
        ⊥ (perpendicular)               ⊥

null(A) ⊥ row(A)          null(Aᵀ) ⊥ col(A)
```

**The four dimensions — rank-nullity everywhere:**

| Subspace | Lives in | Dimension |
|---------|---------|-----------|
| col(A) | $\mathbb{R}^m$ | $r$ |
| null($A^T$) | $\mathbb{R}^m$ | $m-r$ |
| row(A) | $\mathbb{R}^n$ | $r$ |
| null($A$) | $\mathbb{R}^n$ | $n-r$ |

**Two orthogonality facts:**
$$\text{null}(A) \perp \text{row}(A) \quad \text{(in } \mathbb{R}^n\text{)}$$
$$\text{null}(A^T) \perp \text{col}(A) \quad \text{(in } \mathbb{R}^m\text{)}$$

#### TOPIC 4 — Positive Definite Matrices

**Five equivalent conditions — all must be TRUE simultaneously:**

| Condition | Statement |
|-----------|-----------|
| 1 | All eigenvalues $> 0$ |
| 2 | $\mathbf{x}^TA\mathbf{x} > 0$ for all $\mathbf{x}\neq\mathbf{0}$ |
| 3 | $\det(A) > 0$ |
| 4 | All leading principal minors $> 0$ |
| 5 | All diagonal entries $> 0$ |

**What CANNOT happen for PD matrix:**
- Negative eigenvalue ✗
- Zero eigenvalue ✗
- Negative diagonal entry ✗
- Zero determinant ✗

**2×2 shortcut:**
$$\begin{bmatrix}a&b\\b&c\end{bmatrix} \text{ is PD} \iff a>0 \text{ AND } ac-b^2>0$$

---

#### TOPIC 5 — Projection Matrix $(I-P)$

**If $P$ is a projection matrix, then $(I-P)$ is ALSO a projection matrix.**

**Proof:**
$$(I-P)^2 = I - 2P + P^2 = I - 2P + P = I-P \checkmark \text{ (idempotent)}$$
$$(I-P)^T = I^T - P^T = I - P \checkmark \text{ (symmetric)}$$

**Geometric meaning:**

```
Any vector b splits into:
b = Pb + (I-P)b
    ↑         ↑
projection  complement
onto col(A) onto null(Aᵀ)

P projects onto col(A)
(I-P) projects onto null(Aᵀ)
```

#### TOPIC 1 — Hessian Classification — Complete Table

**The ONLY table you need:**

| Condition | $H_{11}$ | $\det(H)$ | Classification |
|-----------|---------|-----------|----------------|
| Positive Definite | $>0$ | $>0$ | **Local Minimum** ✓ |
| Negative Definite | $<0$ | $>0$ | **Local Maximum** ✓ |
| Indefinite | any | $<0$ | **Saddle Point** ✓ |
| PSD | $\geq0$ | $=0$ | **Inconclusive** ✗ |
| NSD | $\leq0$ | $=0$ | **Inconclusive** ✗ |

**Memory device:**
```
det(H) < 0 → SADDLE (always, no exceptions)
det(H) > 0 → check H₁₁:
    H₁₁ > 0 → MIN
    H₁₁ < 0 → MAX
det(H) = 0 → INCONCLUSIVE
```

---

#### TOPIC 2 — Newton's Method Key Properties

**Four properties — all tested:**

| Property | Statement |
|----------|-----------|
| Update rule | $x_{k+1} = x_k - f'(x_k)/f''(x_k)$ |
| Convergence speed | **Quadratic** near solution |
| For quadratic $f$ | Converges in **exactly 1 step** |
| Effect of condition number | **None** — Newton automatically accounts for curvature |

**Why Newton is immune to condition number:**

GD update: $\mathbf{x}_{k+1} = \mathbf{x}_k - \eta\nabla f$ — uses same $\eta$ in all directions

Newton update: $\mathbf{x}_{k+1} = \mathbf{x}_k - H^{-1}\nabla f$ — $H^{-1}$ automatically scales each direction by its curvature

```
High κ landscape:         After H⁻¹ scaling:
Elongated ellipses    →   Perfect circles
GD zigzags            →   Newton goes straight
```

---

#### TOPIC 3 — Convex Function on Closed Interval

**When $f$ is convex on $[a,b]$ with interior critical point $c$:**

```
Global MINIMUM: at c (interior critical point)
Global MAXIMUM: at endpoint(s) a or b

Total global extrema > 1
→ "Multiple global extrema" is correct
→ NOT "single global extremum"
```

**Why "multiple":** The question counts BOTH the minimum and the maximum. Even with one minimum, there is also a maximum at the boundary — total = at least 2.

---

#### TOPIC 4 — Feature Scaling Summary

**Three effects of normalising features before GD:**

$$\text{Scaling} \implies \kappa\downarrow \implies \text{level sets more circular} \implies \text{faster convergence}$$

| Without scaling | With scaling |
|----------------|-------------|
| Features dominate by magnitude | All features equal weight |
| High $\kappa$ | Low $\kappa$ |
| Zigzag path | Direct path |
| Many iterations | Fewer iterations |
| Same optimum (eventually) | Same optimum (faster) |

**Does NOT change:** The location of the optimal solution (same answer, just faster to reach).

#### TOPIC 1 — Precision-Recall-Threshold Relationship

**The complete relationship — memorise this table:**

| Threshold | Predicted positives | TP | FP | FN | Precision | Recall | FPR |
|-----------|--------------------|----|----|----|-----------|--------|-----|
| High (0.9) | Few | Low | Very low | High | **High** | **Low** | Low |
| Medium (0.5) | Moderate | Med | Med | Med | Med | Med | Med |
| Low (0.1) | Many | High | High | Very low | **Low** | **High** | High |

**Two rules to never forget:**

$$\text{Lower threshold} \implies \text{Recall}\uparrow,\ \text{Precision}\downarrow,\ \text{FPR}\uparrow$$

$$\text{Higher threshold} \implies \text{Recall}\downarrow,\ \text{Precision}\uparrow,\ \text{FPR}\downarrow$$

**ROC curve movement:**
```
TPR (Recall)
1│●←──────────────── threshold=0 (everything positive)
 │  ↖ lower threshold moves UP-RIGHT
 │    ↖
 │      ●  ← threshold=0.5
 │        ↖
 │          ●  ← threshold=0.9
0└──────────────────── FPR
0                      1
```

---

#### TOPIC 2 — What Recall=1 Actually Means

**The precise meaning:**

$$\text{Recall} = \frac{TP}{TP+FN} = 1 \implies FN = 0$$

**What it MEANS:** No actual positive is missed.

**What it does NOT mean:**

| Wrong conclusion | Why wrong |
|-----------------|-----------|
| Everything predicted positive | Could still correctly reject some negatives |
| FP = 0 | FP is completely unrelated to Recall |
| Model is perfect | Could have terrible Precision |
| Specificity = 0 | Only true if ALSO predicting everything positive |

**Counterexample:** 10 positives, 10 negatives.

Predict: all 10 positives as positive (TP=10, FN=0) AND 8 negatives correctly (TN=8, FP=2).

Recall = 10/10 = 1.0 ✓ but NOT everything predicted positive.

---

#### TOPIC 3 — AUC — What It Can and Cannot Tell You

**AUC = one number summarising the entire ROC curve.**

$$\text{AUC} = P(\text{model ranks a random positive higher than a random negative})$$

**What AUC tells you:**

| AUC | Meaning |
|-----|---------|
| 1.0 | Perfect ranking — always puts positives above negatives |
| 0.5 | Random — no discrimination ability |
| 0.3 | Worse than random (invert predictions!) |
| 0.9 | Excellent ranking ability |

**What AUC CANNOT tell you:**

| Cannot determine from AUC | Why |
|--------------------------|-----|
| Precision at any threshold | Threshold-specific metric |
| Recall at any threshold | Threshold-specific metric |
| Which threshold to use | Need business context |
| Actual model predictions | AUC is aggregate |

**Key exam trap:** "Model A has higher AUC → Model A has higher Precision" — FALSE. AUC says nothing about Precision or Recall at any specific threshold.

---

#### TOPIC 4 — LOOCV Properties

**The four key properties — ALL tested:**

| Property | LOOCV | k-fold (small k) |
|----------|-------|-----------------|
| Bias of error estimate | **Low** (trains on n-1 points) | Higher |
| Variance of error estimate | **High** (correlated folds) | Lower |
| Model selection tendency | **Complex models** | Simpler |
| Computational cost | **Expensive** ($n$ runs) | Cheaper |

**The most commonly missed property:**

> LOOCV tends to select **MORE complex** models (more parameters) — the OPPOSITE of parsimonious.

**Why:** Each fold uses $n-1$ training points (nearly identical to full dataset). Complex models are not penalised as they would be with more diverse training sets.

---

#### TOPIC 5 — Bias vs Variance — What Reduces What

**Complete table — study until automatic:**

| Action | Effect on Bias | Effect on Variance |
|--------|---------------|-------------------|
| More training data | None | **Decreases** ↓ |
| More complex model | **Decreases** ↓ | Increases ↑ |
| Simpler model | Increases ↑ | **Decreases** ↓ |
| Regularisation | Increases slightly ↑ | **Decreases** ↓ |
| More features | **Decreases** ↓ | Increases ↑ |
| Feature selection | Increases slightly ↑ | **Decreases** ↓ |

**The only thing that reduces variance without increasing bias:**
$$\text{More training data} \implies \text{Variance} \downarrow,\ \text{Bias unchanged}$$

---

#### TOPIC 6 — Sigmoid: PDF vs CDF

**Why sigmoid is a CDF and NOT a PDF:**

| Property | PDF requirement | Sigmoid |
|----------|----------------|---------|
| $\int f(x)dx = 1$ | Must equal 1 | $= \infty$ ✗ |
| $f(x) \geq 0$ | Must be non-negative | ✓ |
| $F(-\infty) = 0$ | CDF requirement | ✓ |
| $F(+\infty) = 1$ | CDF requirement | ✓ |
| Non-decreasing | CDF requirement | ✓ |

**Sigmoid IS the CDF of the logistic distribution.**

Its DERIVATIVE $\sigma(z)(1-\sigma(z))$ is the corresponding PDF — bell-shaped, integrates to 1.

## The 10 Single Most Important Facts

These come up in almost every test you have taken:

```
1. R² = 1 - SSE/SST  (never SSE/SST alone)

2. PDF normalisation: find k first, THEN E[X], THEN Var

3. Eigenvalues: ALWAYS solve det(A-λI)=0, verify with tr and det

4. Symmetric matrix → real eigenvalues (NOT necessarily positive)

5. Lower threshold → Recall↑, Precision↓, FPR↑

6. Recall=1 → FN=0 (does NOT mean everything predicted positive)

7. AUC = ranking ability only (cannot infer Precision or Recall)

8. LOOCV → less bias BUT selects complex models (NOT parsimonious)

9. More data → reduces VARIANCE not bias

10. Hessian PSD → INCONCLUSIVE (not confirmed minimum)
```
